================================================================================
                  🤖 TELEGRAM BOT - 5 MINUTE SETUP
================================================================================

STEP 1: Create Bot on Telegram (2 minutes)
-------------------------------------------
1. Open Telegram app
2. Search for: @BotFather
3. Send command: /newbot
4. Choose name: "My Trading Bot" (or any name)
5. Choose username: "my_trading_bot" (must end with 'bot')
6. COPY THE TOKEN (looks like: 123456789:ABCdefGHIjklMNOpqrsTUVwxyz)


STEP 2: Add Token to Config (1 minute)
---------------------------------------
nano .env

Add this line:
TELEGRAM_BOT_TOKEN=paste_your_token_here

Save: Ctrl+X, Y, Enter


STEP 3: Install & Run (2 minutes)
----------------------------------
./setup_telegram.sh

Or manually:
source venv/bin/activate
pip install python-telegram-bot psutil
python3 telegram_bot.py


STEP 4: Start Using (30 seconds)
---------------------------------
1. Open Telegram
2. Search for your bot username
3. Send: /start
4. Click buttons to control your trading bot!


================================================================================
                           AVAILABLE COMMANDS
================================================================================

/start          - Main control panel with buttons
/start_bot      - Start the trading bot
/stop_bot       - Stop the trading bot
/restart_bot    - Restart the trading bot
/status         - View detailed status
/logs           - View recent logs
/config         - Show configuration
/help           - Help message


================================================================================
                         CONTROL PANEL BUTTONS
================================================================================

▶️ Start Bot       - Launch trading bot
⏹️ Stop Bot        - Stop trading bot gracefully
🔄 Restart Bot     - Restart with new settings
📊 Status          - Real-time status & stats
📝 Logs            - View recent activity
⚙️ Config          - Display settings


================================================================================
                           BACKGROUND MODE
================================================================================

Run with screen (recommended):
screen -dmS telegram-bot python3 telegram_bot.py

Check it's running:
screen -ls

Attach to view:
screen -r telegram-bot

Detach:
Ctrl+A, then D


Or with nohup:
nohup python3 telegram_bot.py > telegram_bot.log 2>&1 &


================================================================================
                            SECURITY TIP
================================================================================

To restrict access to only YOUR Telegram account:

1. Message your bot first
2. Run: python3 get_chat_id.py
3. Copy your Chat ID
4. Add to .env: TELEGRAM_CHAT_ID=your_chat_id


================================================================================
                             TROUBLESHOOTING
================================================================================

Bot not responding?
→ Check: ps aux | grep telegram_bot
→ Logs: tail -f telegram_bot.log

Invalid token?
→ Get new token from @BotFather
→ Update TELEGRAM_BOT_TOKEN in .env

Trading bot won't start?
→ Check: tail -f logs/bot.log
→ Verify .env has all settings
